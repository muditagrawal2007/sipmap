# Installing sipmap

> Created by **MUDIT AGRAWAL** ([@muditagrawal2007](https://github.com/muditagrawal2007)).

Three ways to install. All free.

## Option 1 — Per-repo install (easiest, 60 seconds)

1. Visit the App's public page: `https://github.com/apps/sipmap`
2. Click **Install**
3. Select a repo
4. Done — type `:sipmap /help` on any issue or PR to test

## Option 2 — Share the install link

Add this to your repo's `CONTRIBUTING.md`:

```markdown
## 💬 Use sipmap in your own repos
sipmap is free & open-source (MIT). Install in under a minute:
👉 https://github.com/apps/sipmap
```

Each contributor clicks the link and installs into their own repos.

## Option 3 — Org-wide install

Org owners: visit `https://github.com/apps/sipmap/installations/new`, select **All repositories** (or a filter), and click **Install**. Every current and future repo in the org gets the bot.

Each repo can still commit its own `.sipmap.yml` for per-repo customization.

## After install

You can drop a `.sipmap.yml` in your repo's default branch to customize. See [`config.md`](./config.md). Defaults are sensible.

## Self-hosting

If you'd rather run your own copy of the bot (e.g. inside a corporate network), see [`self-host.md`](./self-host.md) or [`glitch.md`](./glitch.md).
